# Election Atlas

Production route: https://monarchcastle.com/sdcofa/election/

The owned static route is deployed by the main MonarchCastleTech GitHub Pages build. The edge serves this route before its legacy SDCofA fallback. No DNS or legacy forecast API changes are needed.

Run `node scripts/sync-election.mjs` to refresh feeds. The existing hourly Pages workflow runs this before building. Calendar pagination includes both upcoming and campaign phases. Feed requests run independently; failed feeds recover a newer last-deployed snapshot when available, otherwise retain the checked-in successful snapshot, preserve its original timestamp, and publish a failure status. If a feed has no fallback, the build fails. Repeated failures are visible as aging snapshots in the UI. GitHub scheduling and upstream availability determine actual publication time.

Calendar: elekt public API, national scope including territories, referendums and indirect elections. This is upstream coverage, not a guarantee of exhaustive global/local coverage. Date precision and evidence status are retained. Only sourced, day-precise scheduled/snap dates receive countdowns and .ics export. Export follows current filters and is a one-time download, not a subscription. Countries without dates remain searchable.

Polling: DAWUM, federal and state polls published in the last 180 days; Election Wrld / VoteHub, published 2026 US polls. Missing countries show no invented polling. Charts connect individual polls by fieldwork end date within 90 days of the latest observation. They are not averages, predictions, seat estimates, or probabilities. Historic races retain their race labels. Missing metadata is labelled.

Licensing remains separate for each snapshot: German derived polling database ODbL 1.0 (https://opendatacommons.org/licenses/odbl/1-0/), credit dawum.de; US data CC BY 4.0, credit VoteHub / Election Wrld; calendar sources CC0 / CC BY-SA 4.0 with upstream provenance retained via each record's API link. Natural Earth world outlines are public domain and reuse the existing owned map asset. Flag images use FlagCDN and no analytics or credentials. The app uses the existing local IBM Plex font.

No visitor account or API key is needed. All feeds and AI analysis are generated at build time. The browser loads same-origin snapshots, so visitors don't depend on third-party API CORS or expose credentials.

## SDCofA Projects

The user requested both pre-election forecasts and election-night winner calls. `scripts/sync-election-ai.mjs` uses only free model variants and the `openrouter/free` router, with no paid fallback. `OPENROUTER_API_KEY` is an encrypted repository Actions secret. It is never sent to visitors or written into source. `scripts/configure-election-ai.mjs` accepts a replacement key on stdin and uses the authenticated `akgularda` GitHub CLI account to set the secret and generate a local snapshot. A missing key or model outage preserves dated analysis and makes it visibly archived rather than a current announcement.

Forecasts are explicitly conditional: who would take the largest vote share if the election were held today. The first implementation supports eligible German federal/state groups with at least three independent pollsters in thirty days. It takes the latest observation per institute and an unweighted mean; the AI reviews the structured evidence. It does not predict coalition formation, seats, the government, or the eventual election-day result. Confidence labels are qualitative, uncalibrated, and limited to low/medium. There are no fabricated numerical win probabilities.

Election-night calls currently review selected US Senate/governor races from the 2026 general election. The script paginates the results API and retrieves full vote provenance for potentially callable races. Declared primary entrants without reported votes are excluded from the general-election field; missing totals for actual ballot candidates fail the gate. A call requires all reported candidate totals to have official-source provenance, a fresh source timestamp (within 48 hours), estimated reporting at least 99%, a lead of five points, and more than half the reported vote. Alaska, Maine, Louisiana, Georgia and Vermont are excluded pending dedicated ranked-choice/runoff/institutional rules. These criteria are conservative editorial rules, not a mathematically certain remaining-ballot bound or a validated probability model. The AI may still withhold.

Only exact input leaders can become projected winners. Unreviewed, invented, numerically embellished, or unsupported model decisions are rejected. An election-night call is a provisional SDCofA projection, not official certification. Each card exposes its race, scope, source returns, model, generation ID, assumptions, and source links. The separate JSON record includes review outcomes and a bounded corrections/withdrawals history. Current UI announcements expire after 24 hours for forecasts and 48 hours for result calls; delayed refreshes archive the cards. Unchanged input digests reuse validated output, reducing free-model requests. The hourly GitHub schedule is not minute-by-minute live coverage.

Verification: `node --test tests/election-data.test.mjs`, the existing site suite, built-artifact checks, plus desktop/mobile browser inspection. Source URLs and licenses appear in the Sources tab and JSON snapshots.
