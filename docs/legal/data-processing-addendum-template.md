# Data Processing Addendum — issue list/template

Not legal advice. Complete with privacy counsel after the real deployment architecture and data map exist.

Define controller/processor roles; subject matter and duration; processing purpose; data subjects; data categories; special-category prohibition; documented instructions; confidentiality; security measures; subprocessor authorization and list; international transfers; assistance with rights requests; breach notification; DPIA/cooperation; return/deletion; audit evidence; liability hierarchy; governing law.

Minimum technical schedule: tenant isolation, least privilege, MFA, encryption in transit/at rest, secret management, audit logging, tested backups, retention automation, vulnerability management, dependency scanning, incident response, environment separation, access review, deletion verification, and supplier register.

Do not sign until authentication, storage, logs, backup, deletion, hosting location, subprocessors, and incident contacts match deployed reality.
