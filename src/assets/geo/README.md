# Geographic outline

`world.json` contains outer country rings decoded from the Natural Earth 1:110m TopoJSON already bundled in [ESGMap](https://github.com/MonarchCastleTech/esgmap/blob/master/public/geo/countries-110m.json). Natural Earth geographic data is public domain. Conversion preserves longitude and latitude; the source topology is not changed.

The atlas joins published WTI country names to these shapes. Markers use approximate geographic centres of the largest ring and indicate country records, not event locations. Small territories absent at this scale remain available in the country selector. Neither markers nor animation imply measured cross-border flows.

WTI values and timestamps come from its mounted public snapshot. Scores, classifications and publication gates are unchanged.
